Урок 2. Окна

В данном разделе мы рассмотрим однин из важнейших инструментов построения веб-приложений - окна.

 

Когда вы делаете простой сайт, еще можно обойтись без окон. Но сложную систему без окон не построить, ИМХО. Вот именно тут себя Экст проявляет в полной мере, ибо стоит хоть немного понять принципы создания вложенных объектов в Эксте, и надолго перестаешь искать альтернативу.

 

Итак, простой пример.

 

<script type="text/javascript" >
function showWindow(){
	if(!win){
		var win = new Ext.Window({
			width:500,
			height:300,
			title: 'Наше пробное окошко',
			html:'<h1>Тут размещается код HTML</h2>',
			layout:'fit',
			bodyStyle:{'background-color': '#FFFFFF'}
		})	
	}
	win.show();
}
</script>
<input type="button" value="clickMe" onclick="showWindow();" />

 

 

 

Тут на самом деле по-моему все просто и понятно. Единственный момент: layout.Тут мы указываем используемый шаблон для отображения. Различные шаблоны и их свойства перечислены в пакете Ext.layout . В данном случае мы использовали Ext.layout.FitLayout .

 

А дальше начинается самое интересное: вложение объектов UI в объекты. В данном случае я имею ввиду объекты пользовательского интерфейса, такие как таблицы, текстовые поля и т.п. Рассмотрим простейшую форму обратной связи.

 

 

<script type="text/javascript" >
function showFeedbackWin(){
	var feedWin;
	
	if(!feedWin){
		
		
		// Данную функцию будем использовать для проверки заполненности формы
		checkForm = function(){
			var emailForm = Ext.getCmp('email');
			var message = Ext.getCmp('message').getValue();
			var okButton = Ext.getCmp('buttonOK');
			
			// указав vtype:'email', мы можем отслеживать валидные ли данные указаны
			// или нет
			if(emailForm.isValid() == false || !emailForm.getValue() || !message){ 
				// Если не валидно, блокируем кнопку ОК
				okButton.setDisabled(true) ;	
			}
			else{ // Иначе делаем ее активной
				okButton.setDisabled(false) ;	
			}
		}
		
		feedWin = new Ext.Window({
			width:500,
			height:300,
			layout: 'fit',
			bodyStyle:{'background-color': '#FFFFFF'},
			title:'Обратная связь',
			modal: true,
			items:[{		// Элементы окна
				xtype: 'form',		// тип элемента - форма
				bodyStyle: {padding: '10px'},
				items:[{			// Элементы формы
					xtype:'textfield',		// Текстовое поле
					fieldLabel:'Имя',
					id:'name'
				},
				{	
					xtype:'textfield',		// Текстовое поле
					fieldLabel: 'Емейл',
					id:'email',
					vtype:'email',			// Маска ввода, иначе 
									//тип данных
					
					// Указываем что надо обрабатывать события клавишь. 
					//По умолчанию false
					enableKeyEvents: true,	
					listeners:{
						// Не будет обрабатываться keyup, если не 
						// указано enableKeyEvents: true
						keyup:function(){	
							checkForm();
						}	
					}
				}, 
				{
					// Контейнер для элементов формы
					xtype:'fieldset',
					
					// У элемента form по умолчанию layout form.		
					layout:'fit',			 
					
					// Такой шаблон нам не совсем подходит, потому 
					// используем fit
					title:'Поле для сообщения',
					
					// Элементы контейнера
					items:[{				
						xtype:'textarea',
						id: 'message',
						height:110,
						enableKeyEvents: true,
						listeners:{
							keyup: checkForm
						}
					}]
				}]
			}],
			buttons:[{		// Кнопки окна
				text:'Сохранить',
				disabled: true,
				id:'buttonOK',
				handler:function(){		// Функция, вызываемая при клике 
										// по кнопке
					// Используем метод Ext.getCmp для поиска компонента 
					//  по его ID 
					var name = Ext.getCmp('name').getValue();	
					var email = Ext.getCmp('email').getValue(); 
					var message = Ext.getCmp('message').getValue();
					
					var msg = Ext.Msg;
					msg.minWidth = 400; 
					// Выводим сообщение
					msg.alert('Сообщение обратной связи', 
						'Вы указали следующие данные:'+
						'
Имя: '+ name+
						'
Емейл: '+email+
						'
Сообщение: '+message ,
						function(){
							// Закрываем окно
							feedWin.close();	
						}
					);
					 
				}
			},
			{
				text: 'Отмена',
				handler: function(){
					feedWin.close();	
				}
			}]
		});
		
		
	}
	
	feedWin.show();
}
</script>

<input name="button" type="button" onclick="showFeedbackWin();" value="clickMe" />

 

 

Да, вот такая вот простейшая форма... Зато подробная:-)

 

 

Итак, чтоже мы тут имеем?

 

1) Все тот же объект Ext.Window. Как и во всем другом, советую внимательно изучить документацию по данному объекту. Объект очень большой и сложный.

 

2) Больше всего в свойствах нашего окна feedWin нам интересно свойство items. Это массив, содержащий в себе другие объекты, сами по себе являющиеся отдельными объектами Экста. В нашем случае мы использовали краткую форму описания структуры нашего окна, используя свойство xtype. Вообще все компоненты Экста имеют xtype. Список компонентов перечислен в документации (объект Ext.Component). Чтобы было понятней, уточним что xtype: 'form' == new Ext.form.FormPanel(), xtype:'textarea' == new Ext.form.TextArea();
Полная форма описания нашего окна могла бы быть и такой:

 

 

// Создаем текстовое поле Имя
var nameField = new Ext.form.TextField({
	fieldLabel: 'Имя',
	id:'name'
});

// Создаем текстовое поле Емейл
var emailField = new Ext.form.TextField({
	fieldLabel: 'Емейл',
	id:'email'
});

var form = new Ext.form.FormPanel({
	// Перчисляем в массиве элементы формы
	items:[nameField, emailField]		
})

// Создаем окно
var feedWin = new Ext.Window();

// Добавляем к окну элемент form
feedWin.add(form);

// Показываем окно
feedWin.show();

 

 

В данном примере мы сначала отдельно создали нужные нам объекты, затем передали их в качестве свойств другим объектам или просто присоединили функцией add, которая по сути просто к набору элементов items добавляет передаваемый объект. Вообще хочу отметить, что не смотря на кажущуюся сложность Экста, он только сначала труден, потому что просто не привычен. А дальше им уже играешься как хочешь. Главное прочувствовать его, научиться воспринимать все его элементы как объекты. Ведь даже текстовое поле в нем уже не просто текстовое поле, а мощный объект с кучей свойств и методов, и уже нельзя просто получить его value, как мы это делали в чистом javascript, теперь нужно использовать метод этого объекта getValue().
